# Electron 自动更新功能（checkAndUpdate）迁移文档

> 本文档用于将该功能迁移到其他 Electron 项目中。内容包括：依赖、环境变量、运行原理、调用链分析，以及一个可直接使用的简化实现。

---

## 一、功能来源与调用链

```
src/main/index.ts (L182-L184)
  └─ await loadEnvFile()          // ① 把 .env 中 VITE_ 开头的变量写入配置 本项目不需要, 直接读取环境变量
  └─ await checkAndUpdate()       // ② 检查并更新 Electron 启动器应用
       └─ src/main/utils/electron-update.ts (checkAndUpdate)
            ├─ getConfValue('VITE_UPD_URL', '', 'env')   → config.ts
            ├─ getConfValue('VITE_UPD_SLUG', '', 'env')  → config.ts
            ├─ sendInitProgress(pct, msg)                 → window.ts（向渲染进程发 IPC）
            └─ autoUpdater（electron-updater 库）
```

调用时机：`app.whenReady()` 之后、主窗口 `ready-to-show` 回调里，且必须在 `checkAndUpdate()` 之前先调用 `loadEnvFile()`（环境变量是通过它写入配置的）。

## 二、需要安装的依赖

### 2.1 完整版（原项目所用）

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| `electron-updater` | ^6.3.9 | 核心更新库（必须） |
| `electron-log` | ^5.4.3 | 日志输出（可替换为 console） | 本项目直接使用console
| `electron-conf` | ^1.3.0 | 配置存储，`getConfValue` 依赖它读取环境变量 | 本项目不需要, 直接读取环境变量

### 2.2 简化版（推荐，最小依赖）

**只需安装 `electron-updater`**，其余依赖按如下方式替换：

| 原依赖 | 简化替代 |
| --- | --- |
| `electron-log` | `console.log / console.error` |
| `electron-conf` + `getConfValue` | 直接读 `process.env` 或 `import.meta.env` |
| `sendInitProgress`（进度提示） | 改用 `dialog.showMessageBox`，或直接去掉 |
| `electron` | 项目本身就有，无需额外安装 |

## 三、需要设置的环境变量

### 3.1 必需变量（.env 文件，需在构建时注入）

| 变量 | 说明 | 示例 |
| --- | --- | --- |
| `VITE_UPD_URL` | 更新服务器根地址 | `https://upd.devitem.top` |
| `VITE_UPD_SLUG` | 项目唯一标识（slug） | `xxdl-shein` |

### 3.2 可选变量

无

### 3.3 变量读取机制（重要）

原实现里，环境变量读取链路为：

```
.env 文件（构建时由 electron-vite 加载）
  → import.meta.env（只包含 VITE_ 前缀变量）
  → loadEnvFile() 把值写入 conf.json 的 env 命名空间
  → getConfValue('VITE_UPD_URL', '', 'env') 读取
```

**迁移时**：如果新项目用的也是 electron-vite 模板，直接读 `process.env.VITE_UPD_URL` 即可（构建时已注入）；如果是其他构建工具，需自行保证这两个变量在运行时可用。

## 四、它是怎么运行的

### 4.1 更新源 URL 拼接规则

```
feedUrl = ${VITE_UPD_URL}/updates/${VITE_UPD_SLUG}/win32/latest/
示例：  https://upd.devitem.top/updates/xxdl-shein/win32/latest/
```

- 未配置 `VITE_UPD_URL` 或 `VITE_UPD_SLUG` 时，直接返回（记录 warn 日志，不报错）。
- 使用 `provider: 'generic'` 通用源，不走 GitHub 等渠道。
- 该 URL 下必须存放 `latest.yml`（Windows 更新元数据）+ 对应的安装包（如 `xxx-setup-1.0.1.exe`）。

### 4.2 完整执行流程

```
checkAndUpdate()
  1. 拼接 feedUrl；为空则 return
  2. 配置 autoUpdater：
       autoDownload = true            // 发现更新自动下载
       autoInstallOnAppQuit = false   // 不等到退出时安装
       disableWebInstaller = true     // 禁止网页安装器
       setFeedURL({ provider: 'generic', url: feedUrl })
  3. 注册监听器（Promise 封装，任一结果都会 resolve/reject）：
       checking-for-update    → 日志 + 进度 1%
       update-available       → 日志 + 进度 5%（开始下载）
       update-not-available   → 无更新，正常结束
       download-progress      → 进度 5%~95%（按下载百分比映射）
       update-downloaded      → 进度 98%，自动 quitAndInstall(false, true) 重启安装
       error                  → 弹错误框 dialog.showErrorBox + 结束
  4. await autoUpdater.checkForUpdates()
  5. await updateFinished（等待监听器结果）
```

### 4.3 注意事项

- **仅打包后生效**：`electron-updater` 只有在安装版（packaged）应用里才有效；开发环境需 `dev-app-update.yml` 且一般不会真正走更新流程。
- **主窗口 IPC**：原实现通过 `webContents.send('init-progress', ...)` 把进度发给渲染进程。如果新项目不需要进度条，可删除，不影响更新逻辑。
- **更新包发布**：每次发版需要把新的 `latest.yml` 和安装包上传到 feedUrl 对应的目录。
- **调用顺序**：先 `loadEnvFile()`（或等价的环境变量注入）再 `checkAndUpdate()`。

## 五、简化实现（可直接复制，只弹窗提示）

把下面代码放入主进程任意文件（如 `src/main/auto-update.ts`），并在 `app.whenReady()` 后调用一次即可。

```ts
// src/main/auto-update.ts
import { app, dialog } from 'electron'
import { autoUpdater } from 'electron-updater'

const trimTrailingSlash = (value: string): string => value.replace(/\/+$/, '')

export const checkAndUpdate = async (): Promise<void> => {
  const updUrl = process.env.VITE_UPD_URL || ''
  const updSlug = process.env.VITE_UPD_SLUG || ''

  if (!updUrl || !updSlug) {
    console.warn('[auto-update] 未配置 VITE_UPD_URL / VITE_UPD_SLUG，跳过更新检查')
    return
  }

  const feedUrl = `${trimTrailingSlash(updUrl)}/updates/${updSlug}/win32/latest/`

  autoUpdater.autoDownload = true
  autoUpdater.autoInstallOnAppQuit = false
  autoUpdater.disableWebInstaller = true
  autoUpdater.setFeedURL({ provider: 'generic', url: feedUrl })

  // 无更新
  autoUpdater.on('update-not-available', () => {
    console.log('[auto-update] 已是最新版本')
  })

  // 下载完成，弹窗询问是否重启安装
  autoUpdater.on('update-downloaded', async (info) => {
    const { response } = await dialog.showMessageBox({
      type: 'info',
      title: '发现新版本',
      message: `新版本 v${info.version} 已下载完成，是否立即重启安装？`,
      buttons: ['立即重启', '稍后'],
      defaultId: 0,
      cancelId: 1
    })
    if (response === 0) {
      autoUpdater.quitAndInstall(false, true)
    }
  })

  // 出错兜底
  autoUpdater.on('error', (error) => {
    console.error('[auto-update] 检查更新失败:', error)
  })

  console.log(`[auto-update] 检查更新: ${feedUrl}`)
  await autoUpdater.checkForUpdates()
}
```

调用方式（主进程入口）：

```ts
// src/main/index.ts
import { checkAndUpdate } from './auto-update'

app.whenReady().then(async () => {
  // ... 创建窗口等
  await checkAndUpdate()
})
```
